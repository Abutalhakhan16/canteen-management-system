# Common Ground — Campus Canteen Management System

An interactive campus canteen management platform featuring dedicated customer ordering, kitchen operations console, online and offline payment gateways (including dynamic UPI QR codes and apps), and automated pickup token generation.

---

## Key Features

### 1. Differentiated Customer & Admin Interfaces
- **Customer Interface**:
  - Interactive Canteen Menu with categories, search, price, preparation time, and live kitchen indicators.
  - Interactive Tray (Cart) with item quantities (`+` / `-`) and instant total calculation.
  - **My Pickup Tokens**: Real-time tracker for active and past orders, pickup station counter numbers, and live preparation steppers (`Placed` → `Accepted` → `In Kitchen` → `Ready for Pickup` → `Collected`).
  - **Campus Wallet**: Balance dashboard with one-click instant UPI recharge.
  - Seamless header toggle to switch to the Admin Interface anytime.
- **Admin Interface (Operations & Kitchen Console)**:
  - **Live Tokens & Kitchen Queue**: Real-time list of all generated customer tokens with token IDs (`#TK-101`, `#TK-102`), customer details, ordered items, and payment badges.
  - **Status Progression Workflow**: Advance orders through kitchen stages with one click (`Accept Order` → `Start Preparing` → `Mark Ready for Pickup` → `Mark Handed Over`).
  - **Offline Cash Collection**: Visual alerts for orders placed with offline cash and a 1-click **"Mark Cash Received"** button to reconcile payments.
  - **Menu & Stock Management**:
    - **Add New Food Items**: Custom modal with quick templates (Sandwich, Chole Kulche, Chai, Burger, Paneer Meal), custom image URL or device image upload, prices, preparation time, counter station, and tags.
    - **Remove Food Items**: Confirmation modal to safely delete dishes with immediate removal across the app.
    - **Live Availability Toggle**: 1-click toggle between `Available (In Stock)` and `Sold Out / Unavailable`, disabling customer ordering in real time.
    - **Menu Filters & Search**: Filter dishes by stock availability (`In Stock` / `Sold Out`) and category, with live title/description search.
  - **Money Receiving QR & UPI Configuration**:
    - Customize the receiving **UPI ID / VPA** (e.g. `canteen@icici`, `merchant@paytm`).
    - Configure the **Canteen Payee Business Name**.
    - Choose between **Dynamic Auto-Generated UPI QR Code** (auto-embeds customer cart total) or **Custom QR Image** (upload physical counter standee photo or enter image URL).
    - Real-time customer preview in admin console and instant persistence to `localStorage`.
  - **Financials & Analytics**: Real-time breakdown of total revenue, Online (UPI/Cards) vs. Offline (Cash/Wallet) splits, and order volume.
  - **Rush Mode Toggle**: Adds peak preparation delay notices across the customer interface.

---

### 2. Online & Offline Payment Options

#### Online Payments
- **UPI (Unified Payments Interface)**:
  - **Scan UPI QR Code**: Dynamic QR code generated with exact order amount, live 5-minute countdown, and verified checkout.
  - **UPI Apps Direct Intent**: Quick buttons for Google Pay, PhonePe, Paytm, BHIM, Cred, and Amazon Pay.
  - **UPI ID / VPA**: Input field with handle shortcuts (`@okhdfcbank`, `@paytm`, `@okaxis`, etc.) with instant verification.
- **Card Payment Gateway**:
  - Secure credit/debit card gateway interface (Visa, Mastercard, RuPay) with instant test autofill and 256-bit encryption simulation.

#### Offline Payments
- **Pay Cash on Pickup (Counter)**:
  - Place order without upfront payment. Generates a token with `Cash Pending` status to pay at the cashier counter when collecting food.
- **Campus Student Wallet**:
  - Deduct directly from preloaded student campus wallet credits with instant token issuance.

---

### 3. Automated Token Generation & Tracking
- **Sequential Token Generation**: Automatically generates tokens (`#TK-101`, `#TK-102`, etc.) upon checkout completion.
- **Token Slip Modal**:
  - High-visibility pickup token display with estimated ready time and designated counter station (e.g., `Counter 2 (Grill & Rolls)`).
  - Multi-step live preparation progress bar.
  - Itemized receipt breakdown and transaction reference.
  - Built-in "Print / Save Token" action.
- **Shared Live State**: Tokens generated by customers immediately sync to the Admin Kitchen Queue and persist across browser reloads via `localStorage`.

## Getting Started

### Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
pnpm build
# or: npx next build --webpack
```
